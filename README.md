# NOVA — Modern E-Commerce Website

A professional Level 3 HTML + CSS challenge project based on the provided challenge brief.

## Features

- Semantic HTML5 structure
- Responsive CSS Grid and Flexbox
- Modern premium e-commerce UI
- Responsive desktop/tablet/mobile layouts
- 12 product cards
- Category section
- Hero section
- Offer banner
- Newsletter
- Professional footer
- Product category filtering
- Product search
- Wishlist interaction
- Add-to-cart counter
- Mobile navigation
- Hover animations
- Quick-add buttons

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

## Files

- `index.html` — page structure
- `css/style.css` — all styling and responsive design
- `js/script.js` — interactions

Product and hero images use remote Unsplash image URLs, so an internet connection is recommended while viewing the site.
